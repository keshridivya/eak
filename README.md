# EAK International School — Frontend Assignment

A responsive, multi-page frontend concept for a fictional K–12 school.

## Pages
- `index.html` — Home
- `about.html` — About the school, vision, mission and principal's message
- `academics.html` — Learning stages and teaching approach
- `admissions.html` — Five-step admission process, demo enquiry form and FAQs
- `facilities.html` — Facility showcase
- `events.html` — Searchable and filterable sample events/notices
- `contact.html` — Contact details, demo contact form and map placeholder

## Tech
- HTML5
- CSS3
- Bootstrap 5.3 (CDN)
- Vanilla JavaScript

## Run locally
1. Extract the ZIP file.
2. Open the `eak-international-school` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Internet is needed for Bootstrap, Google Fonts and the remote Unsplash images.

## Notes
- All school information, names, numbers, dates, statistics and testimonials are dummy content for a frontend assignment.
- Forms validate in the browser and show a demo message only. No information is submitted or stored.
- Social links are placeholders.
- Replace fictional contact details and verify all content before any real-world use.


## Local image assets
All school-scene visuals used by the HTML pages are now stored locally in the `images/` folder as SVG image files. The HTML pages reference these local files rather than remote Unsplash photo URLs, so the visuals do not depend on an image-hosting site. Bootstrap and Google Fonts still use online CDN links.
